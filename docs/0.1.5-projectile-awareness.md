# Caller-owned projectile awareness

An opt-in sensor for native Projectile entities, default radius32, interval4ticks, linear horizon20ticks, body margin0.5 and maximum128 spatial-index candidates. No global entity map or default goal installation. Snapshots distinguish non-allied and unknown ownership, exclude allies through native or caller-provided owner chains, estimate interception using relative movement and clip projected travel against terrain. Saturation is explicit; refreshes and snapshot reads never modify a projectile or actor. Clear on consumer lifecycle changes; changing level resets the sensor.

It does not identify a projectile payload as damaging, simulate future homing/gravity, detect non-Projectile beams/areas, choose an enemy or grant permission. Consumers own evasion and resource/attack decisions. Goety-specific ownership belongs to consumer adapters, not this API.

Shared regression cases cover owner/source categories, allied servants, approaching/outgoing motion, terrain obstruction, cache reuse, budget and clear. Both loaders compile and package these changes; the tests were not executed and no game was launched. Artifact hashes in 0.1.5-build.json.
