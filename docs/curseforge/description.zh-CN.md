# Ars Instinct

供 Ars 生物使用的通用施法决策库。

**Ars Instinct** 是面向**附属作者与整合包开发者**的库模组，基于 **Ars Nouveau／新生魔艺** 与 **Ars Conflux**。它提供可复用的施法 AI 接口、控制器和感知能力，由使用它的内容模组设计生物、法术组与具体战斗风格。

**单独安装不会让普通生物自动施法。** 本模组不添加生物、装备或魔符，也不全局修改生物的索敌行为。

## 提供的能力

- **通用施法控制器**：使用现成的地面战斗 Goal，或把控制器接到自定义移动与 AI 上。
- **根据能力标签选法术**：读取起始形态和首个主要能力，区分攻击、治疗、增益等用途。
- **选择施法对象**：根据距离、视线、友军关系和有用性条件，在敌人、自身与友军之间选择。
- **考虑资源与冷却**：通过 Conflux 估计首次施法费用，必要时攒蓝等待；实际扣费仍由原生施法路径负责。
- **协调共享冷却**：减少某个编排反复占用共同冷却，让其他可用编排也有释放机会。
- **按需启用的弹射物感知**：通过有范围、有缓存的查询，读取原生弹射物的已知来源与来袭预测；具体反应由使用者实现。

默认 Ars 后端可以读取 Ars 兼容施法工具的多个法术槽，使用真实生物身份施法。现有规划支持**自身、触摸、已登记的弹射物形态与受支持的射线形态**，包括可选的 Not Enough Glyphs 射线联动。

施法沿用 Ars／Conflux 的执行路径，保留资源支付、吟唱、冷却及效果本身的规则。标签只是决策依据，不会授予施法权限或跳过原生限制。

## 给内容开发者

公共接口位于 `dev.arsinstinct.api`：

| API | 用途 |
| --- | --- |
| `SpellCombatController` | 为调用者管理的实体选择并提交合适编排。 |
| `SpellCombatGoal` | 可直接安装的地面施法与近战行为。 |
| `CombatBackend` | 对接工具、编排、资源或自定义选法策略。 |
| `InstinctCasting` | 为指定生物显式安装通用 Goal。 |
| `ProjectileAwareness` | 为自定义战术提供只读的弹射物威胁感知。 |
| `RayForms` | 为其他射线实现提供射程信息。 |

内容模组负责提供施法工具、法术组、资源配置与攻击目标。飞行、后撤、闪避、召唤战术和物种特色仍可由各自模组实现，并复用这里的控制器和感知接口。

魔符能力标签及其数据包覆盖由 **Ars Conflux** 提供，Instinct 负责消费这些信息，避免每种生物分别编写一套 Iron／Goety 专用选法 AI。

## 给整合包作者

**自动安装默认关闭。** 可以通过服务器配置，将指定实体 ID 或 `ars_instinct:spellcasters` 实体类型标签中的生物接入通用 AI，生物进入世界时生效。

这个开关只安装行为，不会给生物发装备、生成法术组或赋予攻击目标。配置也可以为接入的生物覆盖魔力上限与恢复速度；默认保留 Ars 或内容模组的资源设置。

配置文件为世界 `serverconfig` 中的 `ars_instinct-server.toml`，新世界可使用对应的 `defaultconfigs` 预设。
