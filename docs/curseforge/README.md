# Ars Instinct — CurseForge materials

CurseForge Project ID: **1776260**. Binary releases are connected to the shared publisher as `instinct`.

Positioning: developer-facing library, intended to remain library-first as features grow. Gameplay content is supplied by consuming mods.

- `icon.png`: original generated transparent PNG in the author's bucket series.
- `summary.txt`, `description.md`: English summary and Markdown project description.
- `summary.zh-CN.txt`, `description.zh-CN.md`: Chinese alternatives.
- `icon-prompt.txt`, `icon-provenance.json`: built-in imagegen prompt and source record.

Copy the summary and description into the corresponding CurseForge fields. API and Library is the primary category recommendation. These files do not create a project or upload anything.

The public description intentionally promises reusable APIs and explicit opt-in, rather than automatic intelligent combat for every mob.
